colibri · 纯 C 推理引擎，本地跑 MoE 大模型C

新锐项目特点: 纯 C 实现 / 零依赖 / 专家从磁盘流式加载

面向 MoE（混合专家）架构的轻量推理引擎，目标是在消费级硬件上跑前沿大模型。把专家权重按需从磁盘读取，省掉整模型常驻显存的限制，号称"小引擎、大模型"。

关注点：本地部署、隐私可控、低成本。如果你在折腾家用机器跑大模型，这是值得跟进的引擎项目。

open-code-review · 阿里开源的代码评审工具Go

企业级特点: 确定性流水线 + LLM Agent / 行级注释 / 内置多语言规则

混合架构的代码评审工具：先用确定性规则扫 NPE、线程安全、XSS、SQL 注入等常见问题，再让 LLM Agent 兜底补齐上下文理解。支持 OpenAI 与 Anthropic 兼容接口。

关注点：可落地到现有 CI 流水线。比纯 LLM 评审更可控，比纯规则更聪明。

YuE · 音乐生成新版本Python

⭐ 8,377今日 +559特点: 符号化规划 / 零样本翻唱 / Agent 化音乐编辑

面向音乐生成的前沿开源模型，强调"先规划后生成"。可以做零样本翻唱，也支持 Agent 风格的迭代式编辑，更接近"创作工具"而非一次性出曲。

关注点：音乐人、独立游戏、短视频配乐场景的可控生成。

关注点：内容创作、视频本地化、有声书。强调"本地"是它区别于商业 SaaS 的核心卖点。

Agent-Reach · 给 AI 代理配上的网络眼睛Python

特点: 一个 CLI 覆盖 Twitter / Reddit / YouTube / GitHub / B 站 / 小红书免 API 费用

让 AI Agent 能直接读和搜多个社交与内容平台的统一 CLI。不需要各家 API key，把"调研-读-搜"统一成一个接口，方便接入自动化工作流。

关注点：做 Agent 工作流、自动化研究、舆情监控的可以直接拿来用。

localsend · 跨平台 AirDrop 替代Dart

特点: 全平台 / 局域网直传 / 无需互联网

经典开源工具，跨平台的文件互传方案。在没有 Apple 生态或想要 Linux/Windows/Android 互通时，这是最常用的替代。

关注点：日常办公、跨生态文件传输、轻量替代商业方案。

vaultwarden · 用 Rust 自建密码管理器服务Rust

特点: 兼容 Bitwarden 客户端 / 单二进制部署 / 资源占用低

Bitwarden 官方服务的非官方轻量实现，可以用 Rust 部署一个自有密码库，配合官方客户端使用。

关注点：自托管、隐私合规、家庭/团队密码管理。

RuView · 把 WiFi 信号变成空间感知Rust

特点: 基于现有 WiFi 信号 / 无需摄像头 / 实时

利用常见 WiFi 信号的传播特性做空间感知、生命体征监测和存在性检测，号称全程"零像素视频"。

关注点：智能家居、安防、健康监测场景，对摄像头有顾虑的隐私友好方案。

opendisplay · 把 iPad 变成 Mac 的第二显示器Swift

特点: Sidecar/Duet 开源替代 / USB 或 WiFi / H.264 低延迟 / Retina HiDPI / 支持触摸输入

把闲置的 iPhone/iPad 真正当 Mac 的第二屏用。开源、不收费、低延迟，对不愿意为 Sidecar 买 Mac 苹果全家桶的人尤其友好。

关注点：差旅场景、移动办公、给老 Mac 续命一个外接屏。

关注点：乡村/欠发达地区教育、家庭离线图书馆、应急备用信息库。
